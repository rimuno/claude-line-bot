# 『星をひろった夜』 制作バイブル（全エージェント必読）

1分・1920x1080・30fps の2Dアニメ。HTML Canvas 2D で「時間 t → 絵」を決定的に描き、Playwright で全フレームを書き出す。
**Math.random() は使わないこと**（A.rng / A.hash / A.noise を使う。同じ t なら必ず同じ絵）。外部画像は使わず、すべてコードで描く。

## ファイル構成（担当外のファイルは編集しない）
- `lib/core.js` … 共通ユーティリティ（編集禁止・読むこと）。A.tween, A.ease, A.glow, A.camera, A.mouth, A.blink, A.PAL など
- `lib/env.js` … 背景・エフェクト（環境担当）
- `lib/characters.js` … キャラクター（キャラ担当）
- `scenes/*.js` … 各シーン（シーン担当）
- `lib/harness.js` … シーン切替・字幕・ビネット等（監督のみ）
- `timeline.json` / `timeline.js` … 台詞と正確なタイミング（生成物・編集禁止）
- プレビュー: `node tools/preview.mjs 12.5 14`（→ out/preview/t_12.50.png）, `node tools/preview.mjs --sheet s2_meet 12`（コンタクトシート）
- 単体テスト: `node tools/sandbox.mjs mytest.js out/tmp/x.png 1.5`（mytest.js に `window.SANDBOX=(ctx,t)=>{...}`）
- 生成PNGは Read ツールで目視できる。**必ず自分の目で見て品質を確認し、直すこと。**
- 一時ファイルは `out/tmp/<自分の担当名>/` に置く。

## 絵柄
- 日本の劇場アニメ（新海誠・ジブリの夜景）＋絵本の温かさ。フラットな塗りに、柔らかいグラデーション影・リムライト・発光。
- 線画は `A.PAL.ink (#241c3f)` の丸い線（lineJoin/lineCap='round'）、太さはキャラ全高の約1/120。背景は線なし。
- 夜の青紫（night0〜night2, violet）がベース。光は暖色（star, warm, warm2）。光源の色はキャラに映り込ませる（リムライト）。
- 静止した絵は禁止。常に何かが動いている（草のそよぎ、髪の揺れ、呼吸、星のまたたき、ホタル、粒子）。

## 世界
夏の終わりの夜。海沿いの小さな港町を見下ろす「丘」。丘の上は草原（ススキ・小さな白い花・ホタル）。
町: 三角屋根の家々が斜面に並ぶ。窓はたくさん。時計塔が1つ、港に小さな灯台（最初は消えている）。遠景に海と水平線、遠い山並み。
空: 天の川、満ちかけの月（右上）、たくさんの星。夜空の中央上部に「ひとつ星が欠けた」星座の空き（ホシの帰る場所）。

## キャラクター
### ミオ（10歳の女の子, 声=春日部つむぎ）
- 紺色（mioHair）のボブヘア、前髪ぱっつん気味、横の毛先が少し外ハネ。大きな瞳（濃い藍＋上部に水色のグラデ＋白ハイライト2つ）。頬に淡い赤み。
- 水色のワンピース（mioDress）の上にクリーム色の薄手カーディガン（mioCardigan）。赤いスニーカー（mioShoe）。白い靴下。
- 物語の終盤（s5）で、ホシが髪に「星のヘアピン」を残す（`hairpin` パラメータ 0→1 で出現、光る）。それ以前は無し。
- 元気・優しい・まっすぐ。
### ホシ（落ちてきた小さな星, 声=ずんだもん）
- 角の丸い五芒星。淡い金色（star）。中央に顔（大きな黒目がちの目＋ハイライト、小さな口、ほっぺ）。本体の周りに柔らかい発光と小さなキラキラ。
- 下の2つの角が足、左右の角が手のように少し動く（感情表現）。
- 弱っている時: くすんだ色（starDim）で明滅。元気な時: 白金に輝き、光の粒をまとう。
### 町の人
- おじいさん（声=ちび式じい）: 窓/戸口でランタンを掲げる。白い眉と髭、丸眼鏡、茶色のベスト。
- 男の子（声=白上虎太郎）: 窓から身を乗り出してホタルの入ったビンを掲げ、手を振る。

## シーン実装の約束
```js
A.scene('s2_meet', {
  transitionIn: { type: 'fade', dur: 0.6 },   // 'fade' | 'cut' | 'white' | 'black'
  draw(ctx, lt, t, info) { /* lt=シーン内時刻(0..info.dur)、t=全体時刻。トランジションで lt は -0.4〜dur+0.4 になり得るので破綻しないこと */ }
});
```
- 描画の前に ctx 状態を save/restore で必ず戻す。背景は画面全体を塗りつぶす。
- シーン内で複数カットに割ってよい（カット割り・カメラワーク・クローズアップで映画的に）。キャラの顔アップ時は A.camera でズーム。
